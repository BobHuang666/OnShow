# OnShow 用户协议

最后更新:2026-11-01 · 版本:1

## 一、协议的接受

欢迎使用 OnShow(下称「本软件」)。请在首次使用前仔细阅读本协议。您勾选「同意」或实际安装、使用本软件,即视为已阅读并同意本协议全部内容;若不同意,请关闭本软件并删除程序文件。

## 二、软件性质

1. 本软件为免费、开源的 Windows 桌面小工具,源代码发布于 GitHub(BobHuang666/OnShow),按「现状」提供。
2. 本软件代码基于 MIT 许可证发布,许可证与本协议共同生效;两者不一致时,对软件代码的使用以 MIT 许可证为准。

## 三、数据存储与信息安全

1. **全部数据只存在本机**:您的配置、DDL 条目、Token 账户、凭据与运行状态仅保存在本机 `%APPDATA%\OnShow` 目录。本软件不建设、不使用任何自有服务器存储用户数据,没有任何遥测或统计上报。
2. **凭据加密**:您录入的 API Key / Token / Cookie 经 Windows DPAPI(当前用户级)加密后保存于 `tokens.dat`,绑定本机与当前 Windows 账户,复制到其他计算机无法解密;界面不回显明文,配置导出自动脱敏。
3. **请您妥善保管密钥**:请勿将 `tokens.dat` 分享给任何人(包括开发者);向他人反馈问题时请注意先行脱敏。

## 四、网络行为披露

本软件仅在以下三种情形发起网络请求,除此之外不做任何上传:

1. **额度查询**:仅当您配置了对应账户后,定时向 DeepSeek、Z.ai(智谱)、讯飞星火 MaaS 的**官方接口**发起只读查询,用于在面板展示余额/用量;请求内容为您的账户凭据,查询结果缓存在本机。
2. **检查更新**:定时或手动向 GitHub 官方接口查询最新版本;仅在您点击「立即更新」后才下载新版本安装包,下载后进行 SHA256 完整性校验。
3. **问题反馈**:仅当您主动提交反馈时,按第五条所述范围上传。

## 五、反馈功能

通过应用内反馈提交时,上传内容仅限:您填写的文字、您明确添加的截图文件、软件版本与操作系统版本等环境信息。**绝不会包含**您的密钥存储(tokens.dat)与配置文件。反馈通过 GitHub Issue 或您自行选择的渠道(如邮件)送达开发者。

## 六、第三方服务

1. 额度查询与反馈依赖第三方服务(各模型服务商、GitHub 等)。第三方服务的可用性、数据准确性与隐私处理适用其自身条款,开发者不对其承担责任。
2. 您使用各服务商的 API / 额度,需同时遵守其服务条款;费用与额度变动以服务商官方页面为准。
