# OnShow 隐私与信息安全声明

最后更新:2026-11-01 · 版本:1

**一句话:OnShow 不收集您的任何信息。** 您的数据全部留在您的电脑上;联网行为只有「查额度、查更新、您主动提交的反馈」三类。

## 我们保存什么、存在哪里

- 配置(桌面模式、位置、自启动等)→ `%APPDATA%\OnShow\config.json`,不含敏感信息
- DDL 条目 → 本机 `ddl.json`
- Token 账户(名称、服务商、控制台网址)→ 本机 `token.json`,**不含凭据**
- API Key / Token / Cookie → 本机 `tokens.dat`,经 **DPAPI(当前用户)加密**
- 运行状态与滚动日志 → 本机,日志保留 7 天

卸载本软件 = 直接删除程序文件与上述目录,不残留任何云端数据。

## 网络请求清单(仅此三类)

1. 额度查询 → DeepSeek / Z.ai / 智谱 / 讯飞 **官方接口**(仅配置了账户才发生)
2. 版本检查与更新下载 → GitHub 官方接口
3. 问题反馈 → GitHub / 您选择的渠道(仅主动提交时)

没有遥测、没有统计、没有广告 SDK、没有任何「匿名数据收集」。

## 您的密钥安全

- DPAPI 加密绑定本机与当前 Windows 账户,文件被拷走也无法解密
- 界面永不回显明文;配置导出自动脱敏
- 任何时候都不要把 `tokens.dat` 或未经筛选的完整日志发给任何人,包括开发者

## 提交反馈时

应用内反馈只上传:您填写的文字、您明确添加的截图、版本与系统信息。提交前请自查文字与截图中的敏感内容(Cookie、账号、密钥片段等)。
